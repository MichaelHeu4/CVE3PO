Agent install

Deployment guide with prefilled URLs for this instance.

Linux

1. Download installer

wget -O install.sh {{ install_script_url }}

2. Run installation

sudo bash install.sh \
  --binary-url {{ binary_url }} \
  --sha256-url {{ sha256_url }} \
  --api-url {{ api_url }} \
  --token <AGENT_API_TOKEN>

The API token is shown in Modules → CVE3PO Agent.

3. Verify service

sudo systemctl status cve3po-agent.timer --no-pager
sudo systemctl status cve3po-agent.service --no-pager
sudo journalctl -u cve3po-agent -n 100 --no-pager

Windows (64-bit)

1. Download and verify

Open PowerShell as administrator. The download is verified before installation.

$dir = Join-Path $env:ProgramData 'CVE3PO'
New-Item -ItemType Directory -Force $dir | Out-Null
$exe = Join-Path $dir 'cve3po-agent-windows-amd64.exe'
$download = Join-Path $dir 'cve3po-agent-windows-amd64.exe.download'
Invoke-WebRequest -Uri '{{ windows_binary_url }}' -OutFile $download
$expected = ((Invoke-WebRequest -Uri '{{ windows_sha256_url }}' -UseBasicParsing).Content -split '\s+')[0]
if ((Get-FileHash $download -Algorithm SHA256).Hash -ne $expected) { Remove-Item $download; throw 'Checksum mismatch' }
Move-Item -Force $download $exe
Invoke-WebRequest -Uri '{{ agent_config_url }}' -OutFile (Join-Path $dir 'agent.env.example')

2. Configure and test

Copy the example to agent.env for a new installation. Set SOFTWARE_API_URL to {{ api_url }} and enter the token shown in Modules → CVE3PO Agent. Save as UTF-8 and restrict access to the file to administrators and the account running the agent.

$config = Join-Path $dir 'agent.env'
if (-not (Test-Path $config)) { Copy-Item (Join-Path $dir 'agent.env.example') $config }
notepad $config
$env:DRY_RUN = 'true'
& $exe
Remove-Item Env:DRY_RUN

3. Schedule every 15 minutes

$action = New-ScheduledTaskAction -Execute $exe
$trigger = New-ScheduledTaskTrigger -Once -At (Get-Date).AddMinutes(1) -RepetitionInterval (New-TimeSpan -Minutes 15)
Register-ScheduledTask -TaskName 'CVE3PO Agent' -Action $action -Trigger $trigger -User 'SYSTEM' -RunLevel Highest
Start-ScheduledTask -TaskName 'CVE3PO Agent'
Get-ScheduledTaskInfo -TaskName 'CVE3PO Agent'

The SYSTEM account sees machine-wide software and its own per-user registry, not every user's applications. Windows inventory does not automatically confirm removals.
